# Day 03 - Linux Commands Practice

## Commands
1. cd -> to change directory 
2. ls -> to list contents in directory
3. mkdir -> to make directory
4. touch -> to create a file 
5. cat -> to read the contents of file 
6. ps -> to show running process
7. top -> to show all process 
8. ss -tulp -> to show open ports
9. apt install -> to install apps 
10. zcat -> list contents of zip file
11. less,more -> show pagenated view of the long file
12. head -> to show top 10 lines of file
13. tail -> to show bottom 10 lines of file , tail -f -> to watch last lines
14. tee -> to show the output on terminal and store in file
15. wc -> word count of the file
16. sort -> sort the output 
17. cp -> copy
18. mv -> move and rename
19. rm -> remove file 
20. rm -r -> remove files recuresivly 
21. rmdir -> remove directory
22. diff -> difference between two files 
23. ln -> to link files (hardlink , softlink)

## Network commands 

1. Ping -> to ping the domain 
2. dig -> to check dns records
3. ip addr -> to show the system ip addr
